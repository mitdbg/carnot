Eval Harness
As promised, we’re sharing a practice harness (attached) with the same api & scoring logic as the harness we’ll be having you use for the competition itself. This should hopefully allow you to familiarize yourself with the answer submission API, how scoring works, etc., in advance.

You can find this practice harness in the attached zip file, and the README will contain instructions for how to get started. TL;DR you can update the reference_agent file to add in whatever agent you’re planning to use, and run the practice_server to practice submitting answers via the api.  Note that the practice kit currently includes a basic set of questions so that you can confirm your set up is working correctly end to end. However, we also encourage you to do a trial run of your agent on the full competition settings using the existing OfficeQA benchmark (see the instructions for how to do this under “Setting up a realistic practice competition” in the README).

The competition will be run for 6 rounds, with 15 questions each round. Rounds will still be 15 minutes total.
